# upstream/

`manifest.json` is generated by `scripts/sync-upstream.py` and lists, for every imported skill, agent, roster persona, template and playbook, the upstream repository and path it came from.

To refresh imported content from the five upstream repositories:

```bash
mkdir -p /tmp/forge-src && cd /tmp/forge-src
git clone --depth 1 https://github.com/github/spec-kit spec-kit
git clone --depth 1 https://github.com/affaan-m/ECC ECC
git clone --depth 1 https://github.com/msitarzewski/agency-agents agency-agents
git clone --depth 1 https://github.com/mattpocock/skills mattpocock-skills
git clone --depth 1 https://github.com/addyosmani/agent-skills addyosmani-skills
cd /path/to/agent-forge
python3 -I scripts/sync-upstream.py --sources /tmp/forge-src --target .
node scripts/validate.js && node scripts/catalog.js
git diff --stat
```

The sync script regenerates `agents/` (imported ones), `roster/`, `skills/` (imported + merged references), `rules/`, `templates/`, `playbooks/`, `contexts/`. It never touches `commands/`, `hooks/`, `docs/`, `README.md`, `CLAUDE.md`, `agents/orchestrator.md`, `skills/workflow/forge-guide/`, `rules/common/agents.md` or `rules/common/prompt-defense.md`... except that `rules/` is regenerated as a whole: re-apply the two hand-written rule files from git after a sync (`git checkout rules/common/agents.md rules/common/prompt-defense.md rules/README.md`).

Review the diff before committing: upstream changes can introduce new script dependencies (see the "Forge note" comments in `autonomous-loops`, `eval-harness`, `strategic-compact`).
